This program is a Java Swing application called Workout Dataset Explorer.
 It allows you to load a workout dataset from a text file and display all the records in a clear table format.
  Each record includes information such as session ID, workout type, duration, heart rate, calories, intensity,
and the day of the session.

You can also view summary statistics, including the total number of rows, average duration, average heart rate,
 total calories burned, and how many sessions were high intensity. 
 The program also lets you add a new row by typing in the details,
  and it will automatically save the new entry back to the original dataset file.
   A search feature is included as well, which counts how many records contain a word or number you type in.

   Overall, the program provides a simple way to view, update, 
   and search workout data in a text file using a user-friendly graphical interface.
